## ✦ Run locally

This is a static website; there is no package installation or build step.

1. Clone the repository:

   ```bash
   git clone https://github.com/Mohitrath/Portfolio.git
   cd Portfolio
   ```

2. Start a local server (Python 3):

   ```bash
   python -m http.server 8000
   ```

3. Open [http://localhost:8000](http://localhost:8000).

You can also open `index.html` directly in a browser.

## ✦ Deploy

The site is compatible with **Vercel** and **GitHub Pages**.

**Vercel settings**
- Framework preset: **Other**
- Root directory: repository root (`./`)
- Build command: leave empty
- Output directory: leave empty

The production site is linked above. If a new commit is not deployed automatically, trigger a redeployment from the Vercel dashboard.
